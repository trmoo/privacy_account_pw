# 🔐 내 계정 지킴이

고등학교 「정보」 Ⅴ. 디지털 문화 수업용 웹앱입니다.
**내가 가입한 사이트를 찾아 정리하고, 비밀번호가 얼마나 안전한지 검사하고, 안전한 비밀번호를 만드는 법**을

- 관련 성취기준: [12정05-02] 올바른 정보 보호 방법을 실천한다 · [12정05-03] 보안 기술을 활용하여 디지털 윤리를 실천한다

## 화면 구성 (탭 4 · 화면 16 · 확인 문제 63)

| 탭 | 하는 일 |
|---|---|
| 🔎 가입한 사이트 찾기 | 한 곳이 털리면 어디까지 뚫릴까(크리덴셜 스터핑 도미노 실험) · **개인정보 포털 조회 따라 하기**(연습용 화면 8단계 — 가짜 광고 피하기부터 탈퇴 접수까지) · **정리 결정 게임**(가상 조회 결과 12곳) · 포털에 안 나오는 계정 찾기 |
| 🧪 비밀번호 안전 검사 | **검사기** — 해커가 쪼개 보는 모습(흔한 비밀번호·한영 전환 `tkfkdgo`=사랑해·자판 배열·날짜·바꿔치기·낱말 잇기)과 공격 상황 네 가지별 뚫리는 시간 · **해커의 눈**(가상 인물의 SNS로 표적 공격 체험) · 비밀번호 대결 · 길이 vs 종류 실험실 |
| 🛠️ 안전한 비밀번호 만들기 | 규칙은 누가 만들었나(NIST 2003→2017→2025, 90일 변경 실험) · 우리나라 기준과 피할 것 · **만드는 법 네 가지**(도메인 규칙법과 그 약점 · 문장 첫 글자 · 무작위 단어 잇기 · 무작위 생성기) · 2단계 인증·패스키 · **내가 사이트 운영자라면**(가입 규칙을 바꾸면 가상 회원 100명이 어떻게 달라지나) |
| ✅ 마무리 | 종합 확인 문제 · 나의 계정 점검표와 실천 다짐 · **활동지 내려받기(.html)** · 출처와 선생님께 |

주소 끝에 `#check/tester` 처럼 붙이면 그 화면이 바로 열립니다.

## 수업에서 쓰는 법

1. 1차시: 🔎 탭(도미노 실험 → 포털 따라 하기 → 정리 게임) → 🧪 검사기로 내 습관 돌아보기.
2. 2차시: 해커의 눈·대결 → 🛠️ 탭(역사 → 만드는 법 → 운영자 모형) → ✅ 종합 문제·다짐·**활동지 제출**.
3. 공용 컴퓨터라면 수업 끝에 「마무리 → 내 기록 지우기」를 누릅니다.

> 실제 개인정보 포털 조회에는 **본인 명의** 휴대폰·아이핀·신용카드가 필요합니다.
> 교실에서는 연습 화면으로 익히고, 실제 조회는 가정에서 보호자와 함께 하도록 안내해 주세요.

## 개인정보와 안전

- 검사기에 넣은 비밀번호는 **브라우저 안에서만 계산**하고 저장하지 않습니다.
- 배포본에는 **콘텐츠 보안 정책(CSP) `connect-src 'none'`** 이 들어 있어 브라우저가 이 페이지의 모든 통신을 막습니다.
  개발자 도구 「네트워크」 탭에서 직접 확인할 수 있습니다.
- 그래도 학생에게는 **진짜 비밀번호를 넣지 말라**고 가르칩니다 — 「비밀번호 검사」를 핑계로 비밀번호를 모으는 가짜 사이트가 있을 수 있기 때문입니다.
- 문항 기록·점검표·다짐만 그 브라우저에 남고, 학번·이름은 내려받는 활동지 파일에만 들어갑니다.

## 개발

```bash
npm install
npm start            # 개발 서버 (index.html 이 메인 페이지)
npm test             # 시험 (엔진·자료·활동지·운영자 모형)
npm run check:syntax # 소스 전수 검사(문법·저작권·조사·통신 금지·비밀번호 저장 금지·바깥 주소)
npm run build        # dist/index.html 한 파일 (CSP 포함)
npm run check:dist   # 빌드 결과 점검(크기·저작권·CSP·바깥 주소)
```
